### Browser and bundled-library caution

The npm wrapper's MIT license does **not** relicense Chromium, NSS, SwiftShader or bundled fonts. The browser and its extracted libraries remain in ignored `node_modules/`, `.cache/` and temporary test paths, never in the shipped game. The npm SBOM is **not a full binary-component SBOM for Chromium**. If distributing a developer appliance/container with those binaries, independently collect Chromium's third-party notices, NSS/MPL obligations, font licenses and platform-specific source-offer requirements first. That binary compliance closure is outstanding and not claimed here.

## Research licensing decisions

The 59-project [matrix](TECHNOLOGY_MATRIX.md), [ledger](research/LEDGER.md) and [raw source evidence](research/evidence.json) record each candidate. Important legal boundaries:

- **Permissive candidates:** MIT/BSD/Zlib/Apache software generally permits commercial use with retained notices and license-specific conditions. Apache has explicit patent grant/termination conditions; MIT is not an explicit universal patent clearance.
- **Copyleft tools/libraries:** Blender, Krita, Tiled components, Luanti, OpenAL Soft, OpenTTD, Mindustry and Endless Sky have relevant GPL/LGPL/share-alike terms. None of their program code or media is incorporated. Offline use of an editor does not by itself impose its software license on original exports, but included templates/assets must be separately checked.
- **Defold:** custom license restricts commercialization as an engine product. Source available; not treated as standard Apache/open-source licensing.
- **Aseprite:** EULA and source-use/distribution restrictions. Rejected for incorporation/distribution.
- **NvCloth:** actual nested license is NVIDIA Source Code License (1-Way Commercial). Custom redistribution/patent clauses; open-source classification not established. No integration.
- **Sentry server:** current FSL/future Apache licensing, not unrestricted current Apache. Not integrated.
- **Bevy/O3DE:** dual licensing and third-party/asset exceptions require file-level assessment, not just GitHub's single SPDX field.
- **Luanti/Endless Sky/OpenTTD/CDDA:** software and media/base-game files are not one homogeneous license bundle. No assets copied.
- **AI:** inference libraries do not license model weights, datasets, provider APIs, generated voices or images. None are distributed here.
- **Cloud/editor services:** open engine/client code does not grant unrestricted use of a hosted editor/backend or its branding.

## Branding and remaining legal questions

“Omniverse Forge” is the user's project name. The project has **no claimed affiliation** with NVIDIA Omniverse, any other vendor, or researched repository. Conduct trademark/name clearance before a public commercial release. No upstream logo is used in the app. No patent freedom-to-operate opinion has been established.
